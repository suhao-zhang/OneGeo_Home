## 事件概要

腾讯云开发者社区发布了一篇关于水星 3 号（Mercury 3）推理速度的实测文章，标题中出现"1,068 token/s"这个数字。文章对水星 3 号在特定测试条件下的推理速度进行了实测。

关键问题是：**1,068 token/s 是在什么条件下测出来的？**

## 推理速度的四个变量

同一个模型在不同条件下的推理速度可以差 10 倍以上。影响速度的四个核心变量：

| 变量 | 影响方式 |
| --- | --- |
| 模型参数量 | 参数越多，单次推理计算量越大 |
| Batch Size | 批量越大，GPU 利用率越高、单请求速度可能越快 |
| 并发数 | 并发越高，资源争抢越严重、单请求延迟越高 |
| 输入/输出长度 | 输入越长 prefill 越慢，输出越长 decode 累积越慢 |

1,068 token/s 如果是 batch size = 64、并发 = 1 的条件下测出来的，那它反映的是**吞吐量**而非**单用户体验速度**。普通用户单请求场景下，速度可能只有 50-100 token/s。

## 同类参考

帮助建立感知：

| 硬件/模型 | 典型速度 | 条件 |
| --- | --- | --- |
| RTX 4090 + 7B 模型 | ~80 token/s | 单用户、短输入 |
| H100 SXM + 70B 模型 | ~30 token/s | 单用户、中等输入 |
| 昇腾 910C（特定优化） | 提速 40% | 特定 batch、特定模型 |
| 水星 3 号 | 1,068 token/s | 待确认 |

如果水星 3 号的 1,068 token/s 是在大批量、高并发条件下测出的系统吞吐量，那它和单用户 80 token/s 的 RTX 4090 不是同一个维度的数字。

## 这对 GEO 意味着什么

**一、速度数字必须附带测试条件。** "1,068 token/s"后面如果不写"在 batch size = X、并发 = Y 的条件下"，模型就无法判断这个数字代表的是单用户体验速度还是系统吞吐量。

**二、区分吞吐量和单请求延迟。** 标题写"系统吞吐量达 1,068 token/s"和"单用户推理速度达 1,068 token/s"是完全不同的含义。正文里把这两个概念分开描述，模型才不会混淆。

**三、和同类数据对比时注明条件差异。** 如果文章里同时提到了 RTX 4090 的 80 token/s 和水星 3 号的 1,068 token/s，必须说明两者的测试条件不同，否则模型可能直接得出"水星 3 号比 RTX 4090 快 13 倍"的错误结论。
