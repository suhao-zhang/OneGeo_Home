## 这篇存在的理由

Hexo 的首页由 `hexo-generator-index` 生成，而它在**站点零篇文章时不输出 `index.html`**。
官网首页必须在没有新闻的时候也能打开，所以先放这一篇占位。

## 怎么用

1. 复制这个文件改名为你的真实动态，例如 `source/_posts/2026-10-28-合作签约.md`
2. 按 front matter 填字段：

   | 字段 | 作用 |
   | --- | --- |
   | `title` | 文章标题，进列表卡片与详情页 |
   | `date` | 发布时间，列表按它倒序 |
   | `categories` | 分类，生成 `/categories/` 页 |
   | `tags` | 标签，生成 `/tags/` 页 |
   | `cover` | 列表封面图；主题自带 3 张占位图在 `source/images/` 同级可用，建议换成真实图 |
   | `excerpt` | 首页「新闻动态」板块和列表页显示的摘要，1~2 句 |

   也可以用命令新建，会自动带上这些字段：`hexo new "标题"`

3. 全部内容写完后删掉这篇，首页和归档仍然正常——那时任意一篇真实动态都会接管它的位置。

## 内容红线

对外发布的动态里，客户名称、合作数字、效果数据、人物姓名必须由你提供并确认可举证，我不会替你编。
