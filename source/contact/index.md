## 聊之前建议先准备好

1. 站点地址与主要内容的类型（博客 / 产品文档 / 电商详情 / 政策发布）
2. 现在正文是不是不跑 JS 就没有内容（服务端渲染 / 纯前端框架）
3. `robots.txt` 现状，以及有没有拦过未知 User-agent
4. 期望的结果：被引用、被收录，还是只做可达性排查
